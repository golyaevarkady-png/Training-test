# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

- Run: `SPRING_PROFILES_ACTIVE=demo ./mvnw spring-boot:run` (H2, no Docker) or `docker compose up -d db && ./mvnw spring-boot:run` (PostgreSQL), then http://localhost:8080.
- Test: `./mvnw test` (JUnit, boots the app on H2 with the real seed) and `npm test` (Jest + jsdom); both must stay green.
- One test: `./mvnw test -Dtest='Class#method'` or `npx jest <file> -t '<name>'`.
- Layout: Spring Boot API in `src/main/java/com/marlowefinch/ops/` (controllers -> repositories with plain SQL via Spring JDBC, no JPA); frontend is plain JS/HTML/CSS in `src/main/resources/static/` (no build step, inline SVG charts).
- DB: Flyway `V1__schema.sql` + `V2__seed.sql`; the seed is generated by `tools/make_seed.py`, never hand-edit it. SQL must work on PostgreSQL and H2.
- "Today" is pinned to 2026-09-21 via the `Clock` bean in `ClockConfig`; always use `LocalDate.now(clock)`, never the system clock.
- Frontend: everything goes through `initApp(document, fetchImpl)` in `app.js`; tests use the fake API and fixtures in `src/test/javascript/setup/loadApp.js`.
- New element `id` in `index.html` -> add it to `REGISTERED_IDS` in `loadApp.js`, or `harness.test.js` fails.
- If an API response shape changes, update the Jest `FIXTURES` to match.
- Tickets live in `docs/tickets/`; workshop material in `workshop/` and `docs/`.
- pom.xml dependencies are frozen. Any change needs a CHG ticket.
